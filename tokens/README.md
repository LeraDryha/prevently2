# Дизайн-токени

Джерело правди для кольорів, типографіки, відступів, радіусів і тіней.
Формат — JSON, щоб токени можна було споживати і з Figma, і з коду (Tailwind).

## Файли

| Файл | Що описує |
|---|---|
| `colors.json` | Палітра, семантичні ролі |
| `typography.json` | Шрифти, розміри, висоти рядка |
| `spacing.json` | Сітка відступів |
| `radius.json` | Радіуси заокруглень |
| `shadows.json` | Тіні |

## Обмеження

- **Контраст — WCAG 2.2 AA** (мінімум 4.5:1 для тексту). Перевіряти кожну пару.
- Колір ніколи не буває єдиним носієм змісту — дублювати текстом або іконкою.
- Семантика замість «сирих» назв: `color.text.muted`, а не `gray-500`.
