# Інформаційна архітектура

Як продукт влаштований: які в ньому сутності й екрани, як жінка між ними рухається.

| Файл | Що в ньому |
|---|---|
| [`sitemap.md`](sitemap.md) | 14 сутностей продукту з job'ом на кожну, дерево з 8 екранів, навігація з підрахунком тапів до main job, матриця трасування job×екран |
| [`flows.md`](flows.md) | Чотири user flow у Mermaid — MAIN, E1, R4a, R1, разом із порожніми станами, помилками й тупиками |
| [`ia.html`](ia.html) | Та сама ІА сторінкою — розділ «Інформаційна архітектура» на [prevently2.vercel.app](https://prevently2.vercel.app/ia/ia.html) |

**Назви екранів тут — робочі.** В інтерфейсі частина екранів зветься інакше — за
Словником [`voice.md`](../design-system/tone-of-voice/voice.md#назви): «Мої відповіді»,
«Знайти обстеження», «Пройдене», «Копія твоїх даних», «Видалити всі дані».

Маршрути у [вайрфреймах](../wireframes/) беруться тільки з `flows.md`: якщо переходу
немає в жодній діаграмі, його немає й у макеті.
