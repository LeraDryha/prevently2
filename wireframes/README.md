# Вайрфрейми

Структура екранів і потоки без кольору й типографіки — тільки ієрархія та логіка.

## Ключові потоки

1. **Онбординг** — що бачить людина до першого питання, щоб довіритись на 20 питань
2. **Опитувальник** — 5 блоків, прогрес, автозбереження, розгалуження
3. **Червоні прапорці** — пріоритетне повідомлення **над** планом
4. **План** — базовий шар + ризик-орієнтований, джерела, дисклеймер
5. **Порожній-але-не-порожній план** — для 18–25: чому зараз більше нічого не потрібно
6. **Відмітка пройденого** — дата → перерахунок наступної
7. **Експорт** — PDF і резервна копія JSON
