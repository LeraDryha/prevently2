# Концепція

Візуальний напрям: мудборди, пошук стилю, обґрунтування вибору.

Тон із брифу — **тепла, людяна подача**: м'які кольори, менш «медично».
Тема тривожна, і візуал має цю тривогу знижувати, а не підсилювати.

Водночас продукт тримається на **об'єктивності** — тепло не повинно
зчитуватись як несерйозність. Баланс між цими двома полюсами і є
головним завданням концепції.

## Що тут лежить

- Мудборди й напрями
- Обґрунтування обраного напряму
- Приклади подачі медичного контенту без залякування
