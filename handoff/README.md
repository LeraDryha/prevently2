# Handoff

Те, що передається в розробку: специфікації, ассети, чеклісти.

## Чекліст готовності екрана

- [ ] Намальовані всі стани з [таблиці замовлення](../wireframes/_screens.md#стани) — не більше й не менше: стану, якого сценарій не дає, не малюємо
- [ ] Адаптив: mobile → desktop
- [ ] Контраст перевірено (WCAG 2.2 AA)
- [ ] Порядок фокуса й поведінка на клавіатурі описані
- [ ] Тексти вичитані — формулювання відповідають правилам медичного контенту
- [ ] Медичний контент пройшов рецензію лікаря **до** публікації
- [ ] Токени використані замість «сирих» значень

## Що тут лежить

- Специфікації екранів
- Експортовані ассети (іконки, ілюстрації)
- Нотатки для розробки: крайні випадки, поведінка на межах
