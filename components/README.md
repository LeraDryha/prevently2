# Компоненти

Специфікації окремих UI-компонентів: стани, поведінка, доступність.

## Що описує специфікація

- Усі стани: default, hover, focus, active, disabled, error, loading
- Поведінка на клавіатурі й для скрінрідера
- Адаптив: mobile-first, потім десктоп
- Приклади правильного й неправильного вживання

## Специфічні для продукту

| Компонент | Нюанс |
|---|---|
| `QuestionCard` | Один крок опитувальника, автозбереження, кнопка «назад» без втрати відповідей |
| `ProgressBar` | Показує прогрес за адаптивної кількості питань (15–25) |
| `RecommendationCard` | Пункт плану: назва, навіщо, коли, джерело, рівень доказовості, вартість |
| `SourceBadge` | Настанова + рівень доказовості (A/B/C/D) |
| `RedFlagAlert` | Пріоритетне повідомлення над планом — найсильніший акцент в системі |
| `EmptyStateExplained` | «Вам зараз це не потрібно, бо…» — повноцінний результат, не заглушка |
| `Disclaimer` | На плані та в PDF |

Токени беруться з [`../tokens/`](../tokens/), правила складання — у [`../design-system/`](../design-system/).
